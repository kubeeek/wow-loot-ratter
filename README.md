# Loot Ratter
 
> Auto-whisper addon for loot trading in World of Warcraft
 
Loot Ratter automatically whispers party members about loot with the classic *"do you need that?"*. No shame — sniff out every loot piece in the group and be sure you're first to claim it for your alts.

## Features
 
- **Loot summary window** — shows all loot you can wear at the end of each encounter
- **Smart upgrade detection** — only flags items that are actual upgrades for your character
- **Flexible whisper control** — send trade whispers with a single button click, or enable auto-whisper to handle it automatically
- **Visual indicators** — upgrades highlighted in green; items unlikely to trade (looter has worse ilvl) shown in red under the *"their"* label
---
 
## Installation
 
Download the latest release from [CurseForge](https://www.curseforge.com/wow/addons/loot-ratter) and install via the CurseForge client, or extract the folder manually into:
 
```
World of Warcraft/_retail_/Interface/AddOns/
```

## Commands
 
| Command | Description |
|---|---|
| `/lw` | Open the settings panel |
| `/lw help` | Show all available commands |
| `/lw show` | Open the loot summary table |
